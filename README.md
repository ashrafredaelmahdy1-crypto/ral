# EMERA Brand Management System

نظام إدارة براند **إميرا** للملابس الطبية والمنتجات — مبني بـ HTML + CSS + JavaScript خالص.

---

## 🚀 تشغيل المشروع

### الطريقة الأسرع (بدون سيرفر):
افتح ملف `index.html` مباشرة في المتصفح.

### أو استخدم Live Server:
```bash
# إذا كان لديك VS Code مع إضافة Live Server
# انقر بالزر الأيمن على index.html → Open with Live Server

# أو استخدم Python
python -m http.server 8080
# ثم افتح: http://localhost:8080
```

│   ├── customers.js        ← إدارة العملاء
│   ├── new-order.js        ← إضافة طلب جديد
│   ├── orders.js           ← صفحة الطلبات
│   ├── production.js       ← صفحة التنفيذ
│   ├── accounting.js       ← صفحة الحسابات
│   ├── shipping.js         ← صفحة الشحن
│   ├── history.js          ← سجل الطلبات
│   ├── products.js         ← إدارة المنتجات
│   └── app.js              ← نقطة البداية الرئيسية

## 📱 الصفحات

| الصفحة | الوظيفة |
|--------|---------|
| **Dashboard** | ملخص سريع للمبيعات والطلبات والأرباح |
| **العملاء** | إضافة/تعديل/حذف العملاء مع البحث وسجل الطلبات |
| **إضافة طلب** | نموذج طلب جديد مع منتجات متعددة وحساب تلقائي |
| **الطلبات** | عرض كل الطلبات مع تصفية وتأكيد الطلبات |
| **التنفيذ** | الطلبات المؤكدة مع أزرار بدء وإتمام التنفيذ |
| **الحسابات** | تسجيل تكاليف التنفيذ وحساب الربح لكل طلب |
| **الشحن** | الطلبات الجاهزة للشحن مع تأكيد الإرسال |
| **سجل الطلبات** | كل الطلبات مع فلترة متقدمة وعرض تفاصيل كاملة |
| **المنتجات** | إدارة قائمة المنتجات التي تظهر في نماذج الطلبات |

## 🔄 تدفق الطلب

```
جديد (New)
  → تأكيد → مؤكد (Confirmed)
  → بدء التنفيذ → قيد التنفيذ (In Production)
  → تم التنفيذ → جاهز للشحن (Done)
  → تم الشحن → تم الشحن (Shipped)
  → يظهر في سجل الطلبات
```

## 💾 التخزين

جميع البيانات محفوظة في **localStorage** باستخدام المفاتيح:
- `emera_customers` — بيانات العملاء
- `emera_orders` — الطلبات
- `emera_products` — المنتجات
- `emera_counters` — عدادات الـ IDs التلقائية

> ⚠️ البيانات مرتبطة بالمتصفح. لنقل البيانات، استخدم أدوات المتصفح لتصدير localStorage.
